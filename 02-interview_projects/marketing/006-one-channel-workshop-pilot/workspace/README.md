# Lanternfold workshop desk

This is the working folder of Lanternfold, a fictional vendor of configuration review software for small application teams. Today is 2026-11-04 at 09:00 UTC+00:00. The team is preparing a practical online workshop about reviewing a release's configuration changes. These files are the complete source set. The addresses use .test and must never be contacted.

## Start here

In an exercise copy, start with task.md and updates.md supplied with that assignment, then use the map below. The task supplies the requested outcome; updates.md contains dated decisions. A task request may contain a colleague's unverified suggestion. Validate factual claims before reusing them. The material fits on an ordinary laptop and can be read with a text editor. No browser, spreadsheet application, account, install or external research is required. A calculator is enough for the data. A spreadsheet is optional; CSV files can be read as text.

## Map

company/facts.md describes capability limits and commercial wording. company/policy.md covers consent, privacy, evidence and accessibility. campaign/workshop.md has logistics and operational decisions. campaign/content-library.md contains existing asset notes. research/audience.md explains what readers need. sales/requests.md records coordination needs. data/registrations.csv is the latest person-level export; data/channel-results.csv describes the previous small campaign; data/search.csv records a deliberately narrow keyword sample. Each CSV has a header and stable row IDs. data/guide.md defines the columns and denominators.

## Working conventions

All output is an unsent, unpublished draft. Keep source references such as a filename and row ID next to material decisions; formal citations are unnecessary. Do not repeat contact addresses in deliverables when an ID is enough. Task-specific updates override the task's draft suggestions explicitly; company/facts.md and company/policy.md remain authoritative for capability and permission. If a decision is unresolved, show the uncertainty and a safe next action instead of inventing approval.

There is room for different useful results: a focused brief, a small decision table, a plain-text asset, or a checklist. Choose a useful piece and verify it. Volume is not the purpose of this desk.
